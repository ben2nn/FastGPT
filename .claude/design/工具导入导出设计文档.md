# 工具导入导出设计文档

## 背景

admin 导入导出页面目前支持 4 种资源类型：知识库、工作流、模型配置、渠道。需要新增对"工具"的导入导出支持。

此处"工具"指 apps 集合中 `type` 为工具类型的应用，包括：
- `plugin`（工作流工具 workflowTool）
- `toolSet`（MCP 工具集 mcpToolSet）
- `httpToolSet`（HTTP 工具集）

对应常量：`ToolTypeList`（定义在 `packages/global/core/app/constants.ts`）。

## 方案选择

**独立 API 端点**（与现有 dataset/app/model/channel 模式一致）。

理由：遵循现有每个资源类型独立目录的模式，不改动已有代码，风险最低。

## 设计详情

### 1. 导出 API

**文件**: `projects/admin/src/pages/api/extend/tool/exportTools.ts`

- **方法**: POST
- **认证**: JWT（与 app/model 导出一致，从 Authorization/Token header 解析）
- **Body**: `{ parentId?: string }`
- **逻辑**:
  1. 连接数据库，验证 JWT，获取 teamId
  2. 如果提供了 parentId：
     - 验证 parentId 格式（24 位 hex）
     - 调用 `findAppAndAllChildren({ teamId, appId: parentId })` 递归查找
     - 按 `ToolTypeList` 过滤结果
  3. 如果未提供 parentId：
     - 直接查询 `MongoApp.find({ teamId, type: { $in: ToolTypeList } })`
  4. 收集所有工具的 appIds
  5. 检查 `MongoAppVersion.countDocuments({ appId: { $in: appIds } })` 是否超 EXPORT_LIMIT
  6. 查询 versions
  7. 返回 JSON：
     ```json
     {
       "version": "1.0",
       "type": "tool",
       "exportTime": "2026-05-26T...",
       "teamId": "...",
       "apps": [...],
       "versions": [...]
     }
     ```
- **限制**: EXPORT_LIMIT 默认 50000（读取环境变量）

### 2. 导入 API

**文件**: `projects/admin/src/pages/api/extend/tool/importTools.ts`

- **方法**: POST
- **认证**: JWT
- **bodyParser sizeLimit**: 100mb
- **Body**: `{ file, keepOriginalId: boolean, targetParentId?: string }`
- **逻辑**:
  1. 连接数据库，验证 JWT，获取 teamId 和 tmbId
  2. 解析 JSON 文件
  3. 校验 `version === '1.0'` 且 `type === 'tool'`
  4. 验证 apps 和 versions 数组存在
  5. 检查总文档数是否超 IMPORT_LIMIT（默认 50000）
  6. 验证 apps 中的 type 均为工具类型（plugin/toolSet/httpToolSet）
  7. ID 映射处理（同 app 导入逻辑）：
     - keepOriginalId=false 时为所有文档生成新 ID
     - 更新 _id、parentId、appId 等引用
     - 覆盖 teamId、tmbId
  8. 如果提供了 targetParentId，设置 apps 的 parentId
  9. 分批 insertMany（BATCH_SIZE=2000），处理 11000 重复键错误
  10. 返回 `{ success: true, data: { appsCount, versionsCount, warnings? } }`

### 3. 前端 API 函数

**文件**: `projects/admin/src/web/core/extend/api.ts`

新增两个函数：

```typescript
// 工具导出
export const exportTools = async (parentId?: string) => {
  const response = await authFetch(getWebReqUrl('/api/extend/tool/exportTools'), {
    method: 'POST',
    body: JSON.stringify({ parentId })
  });
  if (!response.ok) {
    const err = await response.json().catch(() => ({}));
    throw new Error(err.error || '工具导出失败');
  }
  return response.json();
};

// 工具导入
export const importTools = async (
  file: string | object,
  keepOriginalId: boolean,
  targetParentId?: string
) => {
  const response = await authFetch(getWebReqUrl('/api/extend/tool/importTools'), {
    method: 'POST',
    body: JSON.stringify({ file, keepOriginalId, targetParentId })
  });
  if (!response.ok) {
    const err = await response.json().catch(() => ({}));
    throw new Error(err.error || '工具导入失败');
  }
  return response.json();
};
```

### 4. 前端 UI

**文件**: `projects/admin/src/pages/import-export/index.tsx`

- TabList 新增第 3 个 Tab「工具」（位于工作流和模型配置之间）
- 新增 `ToolTab` 组件，结构与 `AppTab` 类似
- 导出面板：
  - parentId 输入框（可选，placeholder 提示"留空导出全部工具"）
  - 导出按钮
- 导入面板：
  - 文件选择（复用 FileUpload 组件）
  - 保留原 ID 开关
  - 目标父文件夹 ID（可选）
  - 导入按钮
  - 导入结果统计（应用数、版本数）
