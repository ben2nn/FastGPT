# Admin 知识库管理 - 差异修复计划

## 优先级排序（按用户可见影响）

### P0 - 核心功能差异（必须修复）

1. **CreateModal** — 模型选择器应该是下拉框，不是文本输入
   - 创建 `AIModelSelector` 适配组件（使用 `MySelect` + 从 API 获取模型列表）
   - 添加 VLM 模型选择器
   - 添加 `QuestionTip` 提示
   - 使用 `ApiDatasetForm` 处理不同类型的特殊字段

2. **Info 面板** — 应该是可交互的设置面板
   - 添加模型编辑功能（向量模型、索引模型下拉选择）
   - 添加编辑知识库信息（名称、头像、简介）
   - 重建时可选择不同模型
   - 显示 Dataset ID

3. **CollectionCard Header** — 缺少创建/导入菜单
   - 添加创建集合菜单（文件夹、文本集合、手动集合）
   - 添加文件导入入口

4. **CollectionCard** — 缺少训练状态和多选批量操作
   - 添加训练状态标签
   - 添加多选复选框和批量删除
   - 添加 6 秒轮询刷新
   - 显示创建时间和更新时间

### P1 - 重要功能差异

5. **DataCard** — 缺少编辑、导出、插入功能
   - 添加插入数据按钮和弹窗
   - 添加导出功能
   - 数据内容使用卡片布局而非表格

6. **CollectionCard Context** — 缺少分页信息和轮询
   - 暴露 total、pageNum、pageSize
   - 添加轮询机制

7. **List 组件** — 缺少向量模型显示和导出
   - 卡片上显示向量模型名称
   - 添加导出菜单项

### P2 - 次要差异（可后续处理）

8. **Test 搜索测试** — 缺少历史记录和参数调节
9. **MetaDataCard** — 数据卡片 tab 的元数据侧栏
10. **权限管理** — 协作者管理（admin 项目不需要）
11. **i18n 国际化** — admin 项目统一使用中文，不需要 i18n

## 实施顺序

按 P0 → P1 → P2 顺序，每个优先级内按文件依赖顺序执行。
